# VR BOX UNIVERSAL LAUNCHER V29
🥽 VR BOX UNIVERSAL LAUNCHER V29

Your Smartphone. Your Virtual Reality World.

VR BOX UNIVERSAL LAUNCHER is an Android-based VR launcher project designed to transform a smartphone into an immersive virtual reality experience.

Built with Godot Engine 4.3, this project aims to create a modern VR home environment inspired by standalone VR systems.

✨ Features

- 🥽 Immersive VR Home Environment
- 📱 Android Application Launcher
- 🌐 Built-in Web Browser
- ▶️ YouTube Web Support
- 🎬 Cinema Mode
- 👀 Gaze Control
- 🎮 Bluetooth Gamepad Support
- 📲 Touch Gesture Navigation
- 🧭 Gyroscope Head Tracking
- 🗂️ Application Library
- 🌌 Immersive Virtual Environment
